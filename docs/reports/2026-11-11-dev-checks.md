# 開発のセッションによる OBS での細かい動作確認

## はじめに

依頼者の手動のユーザーテストから外した細かい確認を、開発のセッションが OBS で行った結果です。依頼者が PC を使わない時間に、UI Automation でドックを操作しました。課題は 5dt.13 です。

## 検証環境

- ポータブル版の OBS 33.0.1。プラグインはコミット 9ad5701 のビルド
- 操作の道具は `.tmp/2026111103-uia-do.ps1`、`2026111108-set-portrait.ps1`、`2026111121-row-ops.ps1`、`2026111122-read-dialog.ps1`、`2026111123-check-css-copy.ps1`、`2026111124-modal-click.ps1`、`2026111125-preset-delete.ps1`、`2026111126-edit-css-in-props.ps1`
- テスト用の画像は `.tmp/2026111115-test-images/`。依頼者の立ち絵 1 枚を借りた。この文書ではサンプル 6 と呼ぶ。元の大きさは 6,677,703 バイト、寸法は 4000 x 6800

## 検証結果

| 確認 | 結果 |
| --- | --- |
| 行の追加・移動・削除 | 3 行を追加し、2 行目の「上へ」で 1 行目と入れ替わった。1 行目の削除の後、番号が 1 から振り直された。1 行目の「上へ」と最終行の「下へ」は押せない |
| ユーザー ID の前後の空白 | ` <ID> ` と入れた値は、プリセットに空白を除いて保存された |
| 元の画像のファイルの上限 | 54,525,953 バイトのファイルは拒否され、「ファイルの大きさが、上限の50 MBを超えています。」と表示された |
| 元の画像の画素数の上限 | 10001 x 10001 の画像は拒否され、「画像の画素数が、上限の1億画素を超えています。」と表示された |
| 拡張子と中身の不一致 | 中身が png で拡張子が jpg のファイルは拒否され、「拡張子とファイルの中身の形式が異なります。」と表示された |
| 行の埋め込み後の大きさの表示 | 高さ 150px でサンプル 6 が「埋め込み 14 KB (WebP、2 倍)」、高さ 600px で「埋め込み 99 KB (WebP、2 倍)」と表示された |
| 段階的な引き下げ | 高さ 600px で、1000 x 1200 のノイズの画像は 985 KB、1600 x 2000 のノイズの画像は 729 KB で、引き下げは起きなかった |
| CSS のコピー | クリップボードに 1,131,244 文字が入った。`data:image/webp;base64,` は 2 件、`url(` は 2 件ですべて `url("data:`、`@import` は無し |
| 生成した CSS の欄 | 1,555 文字で、画像の部分は `…(134,616文字)` と `…(995,040文字)` に省略された |
| プリセットの保存と読み込み | 「テスト1」を保存した後、行を 1 行削除し高さを 200px に変えた。読み込むと 2 行と 600px に戻った |
| プリセットの削除 | 確認のダイアログの後に削除され、`presets.json` は `{"presets":[]}` になった。確認のダイアログのボタンは `Yes` と `No` の英語だった |

| シーンのファイルの CSS の二重保存 | 新しいソースは `settings.css` が 1,131,422 文字で、private settings には `applied_css_fingerprint` の `1131422:87fce20ed6618888` だけがあった。`applied_css` は無かった |
| 終了 | `Number of memory leaks: 0` |

シーンのファイル全体は 12,247,542 バイトでした。B1 で作った旧名のソースの CSS 5,550,169 文字と、旧名のプラグインの `voice_spotlight.applied_css` 5,550,169 文字が残っているためです。

## 考察

- ドックの細かい動作は、確かめた範囲で期待どおりだと考えています。
- 現実的な画像では、埋め込む画像が 1 MB を超えにくく、段階的な引き下げが働く場面はまれだと推測します。段の選び方は単体テストで確かめています。
- 確認のダイアログのボタンの英語の表示は、軽微な表示の問題として課題 5dt.14 に登録しました。

## 未確認

- 段階的な引き下げが実機で働く場面
